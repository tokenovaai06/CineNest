# CineNest

CineNest is an Android application for movie lovers. It shows a list of movies with posters, descriptions and ratings. Users can add movies to favorites, mark them as watched and add their own movies.

## Main Features

- Movie list with poster, title and rating
- Movie details screen with full description
- Add a movie to favorites
- Mark a movie as watched
- Add your own movie
- Navigation between screens with back navigation

## Tech Stack

- Kotlin
- Jetpack Compose
- Material Design 3
- MVVM architecture (ViewModel + StateFlow)
- Navigation Compose
